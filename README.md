# STEMHUB-BPA

BPA Business Professionals of America 2026 项目说明网站（React + Vite + Tailwind CSS）。

## 本地开发

```bash
pnpm install
pnpm dev
```

## 构建

```bash
pnpm build
```

## 在线访问

部署后访问：<https://jjzhang0.github.io/STEMHUB-BPA/>

## GitHub Pages 设置（重要）

仓库 **Settings → Pages** 中请选择：

- **Source**: Deploy from a branch
- **Branch**: `gh-pages` / `/ (root)`

不要选择 `main` 分支，否则会直接发布源码导致白屏。
